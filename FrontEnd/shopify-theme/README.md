# Syoat Shopify Theme Starter

This starter theme is tailored for **Syoat**, a kids personal care brand focused on ages **5-12**.

## Included
- Brand-first layout with announcement, header, and footer.
- Homepage hero section focused on Syoat's product range: body wash, cream, shampoo, and oil.
- Product categories section with editable cards.
- Trust strip section highlighting safety and audience fit.

## Upload steps
1. Zip the `shopify-theme` folder contents.
2. In Shopify admin, go to **Online Store → Themes**.
3. Click **Add theme → Upload zip file**.
4. Customize text, images, and links in the Theme Editor.
